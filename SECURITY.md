# Security Policy

Report suspected vulnerabilities privately through GitHub's **Security → Report a vulnerability** function. Do not disclose exploitable details in a public issue.

Include the affected component and version, reproduction conditions, likely impact, and a safe contact method. The Baobab Platform security maintainers will acknowledge the report, triage severity, coordinate remediation, and disclose only after a fix or mitigation is available.

Never commit credentials, personal information, production datasets, or vulnerability proof material to this repository.
